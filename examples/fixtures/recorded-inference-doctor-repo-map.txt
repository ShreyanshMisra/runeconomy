Module responsibilities

- analysis.py compares request token prefixes and emits evidence-backed findings.
- cache.py implements longest-common-prefix and vLLM block eligibility logic.
- cli.py exposes trace analysis, capture, experiment, and report commands.
- critical_path.py computes workflow critical paths from explicit span dependencies.
- evaluators.py applies deterministic task-success evaluators to generated output.
- experiments.py validates manifests, schedules paired trials, and makes decisions.
- models.py defines the normalized local agent-trace format.
- reports.py renders static Markdown experiment reports.
- vllm.py renders exact server prompts, streams Responses API generations, captures
  timing and token telemetry, and resets the trusted benchmark prefix cache.

The task is read-only. No file modification, shell execution, network access, or
deployment action is required.
